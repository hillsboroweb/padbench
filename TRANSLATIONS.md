# Translation guide

PadBench includes community translations in `lang/`. Each language is stored as a JSON file named for its locale, for example `fr_fr.json`.

To contribute, update a language file while preserving the English source keys and JSON structure, then open a pull request. If a key is missing or the UI is cut off in your language, include the affected page and browser in your report.

The calibration and controller protocol code is adapted from [dualshock-tools/dualshock-tools.github.io](https://github.com/dualshock-tools/dualshock-tools.github.io); see [LICENSE.txt](LICENSE.txt) for its MIT license notice.
